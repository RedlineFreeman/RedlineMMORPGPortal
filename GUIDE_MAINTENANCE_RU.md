# Руководство по архитектуре и поддержке Arcane Chronicles MMORPG Portal

Данный документ создан для того, чтобы вы могли легко понимать, из каких частей состоит сайт, как его редактировать, изменять статьи, добавлять функции и управлять сервером без необходимости глубоко изучать сложные термины.

---

## 1. Карта файлов проекта: что где находится

| Папка / Файл | За что отвечает | Что в нём можно менять |
|---|---|---|
| `server.ts` | **Главный бэкенд-сервер Express** | Порт (3000), API отдачи данных телеметрии сервера, файлы для админки |
| `src/App.tsx` | **Главный дирижёр сайта** | Переключение вкладок (каталог, чтение, админка, редактор), состояние пользователя |
| `src/types/index.ts` | **Словарь терминов (типы)** | Описание того, из чего состоит Статья (`Article`), Пользователь (`User`), Сезон (`Season`) |
| `src/data/initialArticles.ts` | **Каталог статей по умолчанию** | Стартовые статьи Lineage 2, WoW, PoE 2, тексты, картинки, гайды |
| `src/data/authData.ts` | **Данные авторизации и сервера** | Логин/пароль админа (`admin@arcane.ru`), начальные порты, файлы |
| `src/utils/audio.ts` | **Звуковой движок** | Звук треска костра, щелчки монет таверны, звон рун |
| `src/components/PortalHeader.tsx` | **Шапка сайта** | Название портала, логотип, кнопки выбора игр, кнопка костра, профиль |
| `src/components/PortalHero.tsx` | **Баннер каталога** | Поисковая строка, фильтры игр и категорий |
| `src/components/ArticleCard.tsx` | **Карточка статьи** | Как статья отображается в сетке: обложка, бейдж игры, лайк, закладка |
| `src/components/ArticleReader.tsx` | **Страница чтения статьи** | Полный текст манускрипта, блок комментариев, кнопка «Поделиться» |
| `src/components/ArticleEditor.tsx` | **Редактор новых статей** | Форма создания гайда, выбор игры, форматирование текста, публикация |
| `src/components/AdminPanel.tsx` | **Панель Администратора** | Мониторинг CPU/RAM, перезапуск Docker, файловый менеджер, смена сервера |
| `src/components/CozyCampfireFooter.tsx` | **Уютный футер с костром** | Панорама лагеря, кнопки «Присесть на бревно», переключатель сезонов (зима/весна/лето/осень) |
| `src/components/SeasonalAccumulation.tsx` | **Снежные шапки и осенние листья** | Форма снега на карточках и кнопках зимой, кленовые листья осенью |
| `src/components/SeasonWeatherOverlay.tsx` | **Падающий снег/листопад** | Анимация падающих снежинок, осенних листьев или лепестков сакуры |

## 2. Нужно ли быть программистом, чтобы поддерживать этот портал?

**Нет, не нужно! И вот почему:**

1. **Всё основное управляется прямо из интерфейса (без кода):**
   * **Написание статей:** прямо на сайте есть кнопка **«Написать»** с удобным визуальным редактором. Вы вводите заголовок, текст, прикрепляете картинку — статья сразу появляется в каталоге.
   * **Управление файлами сервера:** в панели администратора (вкладка *«Файлы сервера»*) встроен веб-редактор, где вы прямо в браузере можете править конфиги (`.env`, `docker-compose.yml`, Nginx) без консоли.
   * **Мониторинг сервера:** показатели процессора, памяти и контейнеров считываются автоматически.

2. **Если вы захотите что-то поменять в коде:**
   * Код разбит на маленькие понятные файлы (1 файл = 1 задача).
   * Вы всегда можете скопировать любой файл или спросить AI-помощника: *«Я хочу добавить в шапку новую кнопку — в какой файл это написать?»*, и получите точную строчку.

## 3. Как поменять простые вещи своими руками

### Пример 1. Как добавить новую статью в код навсегда?
Откройте файл `src/data/initialArticles.ts`. Найдите массив `INITIAL_ARTICLES` и скопируйте любой блок `{ ... }`:
```typescript
{
  id: 'my-new-guide',
  title: 'Мой новый гайд по Lineage 2',
  subtitle: 'Как быстро прокачаться с 1 по 85 уровень',
  content: 'Текст вашего гайда...',
  game: 'Lineage 2', // или 'World of Warcraft', 'Path of Exile 2'
  category: 'builds',
  authorName: 'Станислав',
  likes: 42,
  isLiked: false,
  isBookmarked: false,
  comments: []
}
```

### Пример 2. Как изменить пароль или логин администратора?
Откройте файл `src/data/authData.ts` на строке 10:
```typescript
export const DEFAULT_ADMIN: User = {
  id: 'admin_1',
  username: 'Архимаг Станислав',
  email: 'admin@arcane.ru', // <-- ваш логин
  role: 'admin',
  title: 'Хранитель Хроник & Root',
};
```

### Пример 3. Как поменять название сайта в шапке?
Откройте файл `src/components/PortalHeader.tsx` и найдите строку со словами `Arcane Chronicles`. Замените на любое своё название (например, `Redline MMORPG Hub`).

## 4. Памятка по управлению сайтом на сервере (команды в терминале)

Если вам нужно перезапустить или обновить сайт на вашем VPS:

```bash
# 1. Зайти в папку сайта:
cd /opt/arcane-portal

# 2. Если поменяли код, пересобрать фронтенд:
npm run build

# 3. Перезапустить сервер через PM2:
pm2 restart arcane-portal

# 4. Посмотреть статус работы:
pm2 status

# 5. Посмотреть живой журнал ошибок, если что-то не работает:
pm2 logs arcane-portal
```
